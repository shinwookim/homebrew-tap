# Shinwookim Tap

## How do I install these formulae?

`brew install shinwookim/tap/<formula>`

Or `brew tap shinwookim/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "shinwookim/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
